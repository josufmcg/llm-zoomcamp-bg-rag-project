# Usage Guide

How to use the BG2 RAG Character Guide system.

## Asking Questions (Streamlit UI)

1. Open `http://localhost:8501` in your browser.
2. Type a question about Baldur's Gate II character creation, e.g.:
   - "What is the best Fighter kit for dealing damage?"
   - "Should I play a Mage or Sorcerer?"
   - "What class is good for beginners?"
   - "How does the Monk's Quivering Palm work?"
   - "Which Paladin kit is best against undead?"
3. Select a search method in the sidebar:
   - **Hybrid** (default) — combines semantic and keyword search
   - **Vector** — pure semantic similarity
   - **Keyword** — traditional full-text search
4. Click "Ask" and wait for the answer.
5. Rate the answer with 👍 or 👎.

## Using the API Directly

The FastAPI backend exposes a REST API on port 8000.

### Interactive API Docs

Open `http://localhost:8000/docs` for the Swagger UI with all endpoints.

### Search

```bash
# Hybrid search (default)
curl "http://localhost:8000/search?q=best+fighter+kit&method=hybrid&limit=3"

# Vector search only
curl "http://localhost:8000/search?q=spellcasting+class&method=vector&limit=5"

# Keyword search
curl "http://localhost:8000/search?q=backstab+stealth&method=keyword"
```

### Ask a Question

```bash
curl -X POST http://localhost:8000/ask \
  -H "Content-Type: application/json" \
  -d '{"question": "What is the best Fighter kit?", "search_method": "hybrid"}'
```

Response includes: answer, token counts, response time, cost, conversation_id, and relevance judgment.

### Submit Feedback

```bash
curl -X POST http://localhost:8000/feedback \
  -H "Content-Type: application/json" \
  -d '{"conversation_id": 1, "score": 1}'
```

### Ingest New Documents

```bash
curl -X POST http://localhost:8000/documents \
  -H "Content-Type: application/json" \
  -d '{
    "documents": [{
      "category": "Character Creation",
      "subcategory": "Multi-class",
      "question": "How do multi-class characters work?",
      "text": "Multi-class characters combine two or three classes..."
    }]
  }'
```

## Monitoring (Grafana)

1. Open `http://localhost:3000` (login: admin/admin).
2. Go to Dashboards → "BG RAG Dashboard".
3. The dashboard shows:
   - Total conversations, average response time, total cost
   - Cost and response time over time (charts)
   - Judge relevance distribution (pie chart)
   - User feedback summary (thumbs up/down)
   - Recent conversations table

### Generating Test Data

To populate the dashboard with sample data for testing:

```bash
make sample-data
# Press Ctrl+C after a few seconds
```

## Running Evaluation

### Generate Ground Truth

```bash
make ground-truth
```

This creates `data/ground_truth.csv` with ~55 test questions (5 per character class), generated by OpenAI.

### Evaluate Search Quality

```bash
make evaluate
```

Output:
```
Method     Hit Rate@5        MRR@5    Queries
vector         0.8545       0.7636         55
keyword        0.6909       0.5818         55
hybrid         0.9091       0.8182         55
```

Best method by MRR is typically `hybrid`.

## Makefile Reference

Run `make help` to see all available targets:

```
make setup           Install deps + download ONNX model
make db              Start local PostgreSQL container
make init-db         Create database tables
make ingest          Ingest bg_characters.json into DB
make dev-api         Run FastAPI on port 8000
make dev-streamlit   Run Streamlit on port 8501
make dev-dashboard   Run Dashboard on port 8502
make build           Build all Docker images
make up              Start all services
make down            Stop all services
make logs            Tail logs
make ground-truth    Generate ground truth Q&A pairs
make evaluate        Run search evaluation metrics
make sample-data     Generate fake data for dashboard
make clean           Remove containers and volumes
```
