## Database Design

### Single Database: `bg_rag`

All tables live in one PostgreSQL database with the `pgvector` extension enabled.

### Table: `documents`

Stores the knowledge base documents with their vector embeddings.

| Column | Type | Constraints | Description |
|--------|------|-------------|-------------|
| `id` | `SERIAL` | `PRIMARY KEY` | Auto-increment ID |
| `doc_id` | `TEXT` | `NOT NULL` | Human-readable ID (e.g., "fighter") |
| `doc_hash` | `TEXT` | `UNIQUE NOT NULL` | MD5 hash for deduplication |
| `category` | `TEXT` | `NOT NULL` | Always "Character Creation" |
| `subcategory` | `TEXT` | `NOT NULL` | Class name (e.g., "Fighter") |
| `question` | `TEXT` | `NOT NULL` | Natural-language question |
| `text` | `TEXT` | `NOT NULL` | Full class description |
| `embedding` | `vector(384)` | | 384-dim vector from all-MiniLM-L6-v2 |
| `text_search` | `tsvector` | | Full-text search index column |
| `created_at` | `TIMESTAMP WITH TIME ZONE` | `DEFAULT NOW()` | Creation timestamp |

**Indexes:**
- `UNIQUE INDEX` on `doc_hash` (for dedup)
- `ivfflat` index on `embedding` using cosine distance (for vector search)
- `GIN` index on `text_search` (for full-text search)

**The `text_search` column** is a generated `tsvector` that combines `subcategory` (weight A), `question` (weight B), and `text` (weight C) for weighted full-text search.

### Table: `conversations`

Stores each RAG conversation with its metrics.

| Column | Type | Constraints | Description |
|--------|------|-------------|-------------|
| `id` | `SERIAL` | `PRIMARY KEY` | Auto-increment ID |
| `question` | `TEXT` | `NOT NULL` | User's question |
| `answer` | `TEXT` | `NOT NULL` | RAG-generated answer |
| `model` | `TEXT` | `NOT NULL` | LLM model name |
| `search_method` | `TEXT` | `NOT NULL` | "vector", "keyword", or "hybrid" |
| `prompt` | `TEXT` | `NOT NULL` | Full prompt sent to LLM |
| `prompt_tokens` | `INTEGER` | `NOT NULL` | Input token count |
| `completion_tokens` | `INTEGER` | `NOT NULL` | Output token count |
| `total_tokens` | `INTEGER` | `NOT NULL` | Total token count |
| `response_time` | `FLOAT` | `NOT NULL` | Time in seconds |
| `cost` | `FLOAT` | `NOT NULL` | Estimated cost in USD |
| `timestamp` | `TIMESTAMP WITH TIME ZONE` | `NOT NULL` | When the conversation happened |

### Table: `feedback`

Stores both user feedback (thumbs up/down) and LLM-as-judge evaluations.

| Column | Type | Constraints | Description |
|--------|------|-------------|-------------|
| `id` | `SERIAL` | `PRIMARY KEY` | Auto-increment ID |
| `conversation_id` | `INTEGER` | `REFERENCES conversations(id)` | FK to conversations |
| `source` | `TEXT` | `NOT NULL` | "user" or "judge" |
| `relevance` | `TEXT` | | Judge verdict: "RELEVANT", "PARTLY_RELEVANT", "NON_RELEVANT" |
| `explanation` | `TEXT` | | Judge explanation |
| `score` | `INTEGER` | | User feedback: +1 or -1 |
| `timestamp` | `TIMESTAMP WITH TIME ZONE` | `NOT NULL` | When feedback was given |

## Detailed Instructions

### Step 1: Create `src/bg_rag/db.py`

```python
"""Database connection management and schema initialization."""

import hashlib
from datetime import datetime, timezone

import psycopg
from psycopg.rows import dict_row

from bg_rag.config import get_settings

# Module-level connection pool (initialized lazily)
_pool = None


def get_db_connection() -> psycopg.Connection:
    """Get a new database connection using settings from config."""
    settings = get_settings()
    return psycopg.connect(
        host=settings.postgres_host,
        port=settings.postgres_port,
        dbname=settings.postgres_db,
        user=settings.postgres_user,
        password=settings.postgres_password,
        row_factory=dict_row,
    )


def init_db(drop: bool = False) -> None:
    """Initialize database tables and extensions.

    Args:
        drop: If True, drop existing tables before creating them.
    """
    conn = get_db_connection()
    try:
        with conn.cursor() as cur:
            # Enable pgvector extension
            cur.execute("CREATE EXTENSION IF NOT EXISTS vector")

            if drop:
                cur.execute("DROP TABLE IF EXISTS feedback CASCADE")
                cur.execute("DROP TABLE IF EXISTS conversations CASCADE")
                cur.execute("DROP TABLE IF EXISTS documents CASCADE")

            # Documents table
            cur.execute("""
                CREATE TABLE IF NOT EXISTS documents (
                    id SERIAL PRIMARY KEY,
                    doc_id TEXT NOT NULL,
                    doc_hash TEXT UNIQUE NOT NULL,
                    category TEXT NOT NULL,
                    subcategory TEXT NOT NULL,
                    question TEXT NOT NULL,
                    text TEXT NOT NULL,
                    embedding vector(384),
                    text_search tsvector,
                    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
                )
            """)

            # Update text_search column with weighted tsvector
            # This trigger automatically updates text_search when a row is inserted/updated
            cur.execute("""
                CREATE OR REPLACE FUNCTION documents_text_search_update() RETURNS trigger AS $$
                BEGIN
                    NEW.text_search :=
                        setweight(to_tsvector('english', COALESCE(NEW.subcategory, '')), 'A') ||
                        setweight(to_tsvector('english', COALESCE(NEW.question, '')), 'B') ||
                        setweight(to_tsvector('english', COALESCE(NEW.text, '')), 'C');
                    RETURN NEW;
                END
                $$ LANGUAGE plpgsql
            """)

            cur.execute("""
                DROP TRIGGER IF EXISTS documents_text_search_trigger ON documents
            """)

            cur.execute("""
                CREATE TRIGGER documents_text_search_trigger
                    BEFORE INSERT OR UPDATE ON documents
                    FOR EACH ROW
                    EXECUTE FUNCTION documents_text_search_update()
            """)

            # Indexes for documents
            cur.execute("""
                CREATE INDEX IF NOT EXISTS idx_documents_text_search
                ON documents USING GIN (text_search)
            """)

            # Note: ivfflat index requires data to exist. We'll create it
            # after ingestion. For now, pgvector will use exact search.
            # The index creation is in ingest.py after bulk insert.

            # Conversations table
            cur.execute("""
                CREATE TABLE IF NOT EXISTS conversations (
                    id SERIAL PRIMARY KEY,
                    question TEXT NOT NULL,
                    answer TEXT NOT NULL,
                    model TEXT NOT NULL,
                    search_method TEXT NOT NULL,
                    prompt TEXT NOT NULL,
                    prompt_tokens INTEGER NOT NULL,
                    completion_tokens INTEGER NOT NULL,
                    total_tokens INTEGER NOT NULL,
                    response_time FLOAT NOT NULL,
                    cost FLOAT NOT NULL,
                    timestamp TIMESTAMP WITH TIME ZONE NOT NULL
                )
            """)

            # Feedback table
            cur.execute("""
                CREATE TABLE IF NOT EXISTS feedback (
                    id SERIAL PRIMARY KEY,
                    conversation_id INTEGER REFERENCES conversations(id),
                    source TEXT NOT NULL,
                    relevance TEXT,
                    explanation TEXT,
                    score INTEGER,
                    timestamp TIMESTAMP WITH TIME ZONE NOT NULL
                )
            """)

        conn.commit()
        print("Database initialized successfully.")
    finally:
        conn.close()


def compute_doc_hash(category: str, subcategory: str, question: str, text: str) -> str:
    """Compute MD5 hash for document deduplication.

    Args:
        category: Document category.
        subcategory: Document subcategory.
        question: Document question.
        text: Document text content.

    Returns:
        MD5 hex digest string.
    """
    content = f"{category}|{subcategory}|{question}|{text}"
    return hashlib.md5(content.encode("utf-8")).hexdigest()


def now_utc() -> datetime:
    """Get current UTC datetime with timezone info."""
    return datetime.now(timezone.utc)


if __name__ == "__main__":
    print("Initializing database (drop and recreate)...")
    init_db(drop=True)
```

### Step 2: Ensure PostgreSQL is running

Start the local PostgreSQL container:

```bash
make db
```

This runs `pgvector/pgvector:pg17` on port 5432. Wait until it says "database system is ready to accept connections".

### Step 3: Initialize the database

In a separate terminal:

```bash
make init-db
```

Or run directly:

```bash
uv run python -c "from bg_rag.db import init_db; init_db(drop=True)"
```

## Verification Checklist

1. **PostgreSQL is running and accepts connections:**
   ```bash
   PGPASSWORD=password psql -h localhost -U user -d bg_rag -c "SELECT 1"
   ```
   Expected: a result row with `1`.

2. **pgvector extension is installed:**
   ```bash
   PGPASSWORD=password psql -h localhost -U user -d bg_rag -c "SELECT extname FROM pg_extension WHERE extname='vector'"
   ```
   Expected: `vector` in the output.

3. **All three tables exist:**
   ```bash
   PGPASSWORD=password psql -h localhost -U user -d bg_rag -c "\dt"
   ```
   Expected: `documents`, `conversations`, `feedback` tables listed.

4. **Documents table has correct columns:**
   ```bash
   PGPASSWORD=password psql -h localhost -U user -d bg_rag -c "\d documents"
   ```
   Expected: columns include `id`, `doc_id`, `doc_hash`, `category`, `subcategory`, `question`, `text`, `embedding` (vector(384)), `text_search` (tsvector), `created_at`.

5. **The text_search trigger exists:**
   ```bash
   PGPASSWORD=password psql -h localhost -U user -d bg_rag -c "SELECT tgname FROM pg_trigger WHERE tgname='documents_text_search_trigger'"
   ```
   Expected: `documents_text_search_trigger` in output.

6. **Python module can connect:**
   ```bash
   uv run python -c "from bg_rag.db import get_db_connection; conn = get_db_connection(); print('Connected'); conn.close()"
   ```
   Expected: `Connected`

7. **compute_doc_hash produces consistent results:**
   ```bash
   uv run python -c "
   from bg_rag.db import compute_doc_hash
   h1 = compute_doc_hash('Character Creation', 'Fighter', 'What is Fighter?', 'The fighter is...')
   h2 = compute_doc_hash('Character Creation', 'Fighter', 'What is Fighter?', 'The fighter is...')
   assert h1 == h2, 'Hashes should be identical for same input'
   print(f'Hash: {h1}')
   print('Hash consistency OK')
   "
   ```
   Expected: A hex string followed by `Hash consistency OK`.
